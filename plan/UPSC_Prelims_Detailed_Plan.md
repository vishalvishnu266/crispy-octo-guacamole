# UPSC CSE Prelims – Detailed 5-Month (22-Week) Study Plan

**Plan window:** Mon 2 Nov 2026 → Sun 4 Apr 2027 (22 weeks)
**Exam:** Prelims 2027 is expected in late May 2027. Check the exact date in the UPSC calendar at upsc.gov.in.
Any weeks between 4 Apr and the exam go into the **Bonus Phase** at the end of this file.

> **Assumption:** about 8 productive hours a day, 6 days a week, with Sunday for tests and revision.
> If you work full-time (4–5 hrs/day), see **Section 10: Working-Professional Adjustment**.

---

## 0. The Strategy in One Page

| Principle | What it means in practice |
|---|---|
| PYQ-first | Before you start a topic, read the last 12 years of PYQs on it. After finishing it, solve them. |
| Limited sources | One book per subject. Revise it 3–4 times rather than reading 3 books once. |
| Current affairs daily | 1.5 hrs every day. Link each news item to a static topic. |
| CSAT daily | 1 hr every day from Day 1, without exception. You need 66/200 to qualify. |
| Test from Week 3 | Take a weekly sectional test now, then full mocks in the final 8 weeks. |
| Short notes | Keep one notebook (or digital file) per subject, at most 20–40 pages each. You will revise from these. |
| Mistake register | Note every wrong answer with the reason (didn't know / misread / over-guessed). |

## 8. Current Affairs System (daily, 1.5 hrs)

1. **Read** (45 min): newspaper (The Hindu/IE), or a daily CA site (Vision/Insights/ForumIAS) if you're short on time.
2. **Filter**, asking "Can UPSC ask a factual question on this?" Focus on:
   - Species, places, protected areas, rivers in the news
   - New schemes, missions, bills, acts, judgments
   - Reports and indices, international organisations
   - S&T terms (new tech, diseases, space missions)
3. **Note** (30 min): one-liners in a digital file, arranged **by subject, not by date**.
4. **Link** (15 min): connect each item to a static topic (e.g. "Repo rate cut" → monetary policy notes).
5. **Monthly:** finish one monthly magazine in the last week of each month.

## 11. Mock Test Analysis Template

After every mock, fill in:

| Mock # | Date | Attempted | Correct | Wrong | Score | Cut-off est. | Weakest subject |
|---|---|---|---|---|---|---|---|
| 1 | | | | | | ~90 | |
| 2 | | | | | | ~90 | |
| ... | | | | | | | |

**For each wrong answer, put it in one of these buckets:**
- **A – Didn't know the fact** → add it to the short notes
- **B – Knew it but misread or confused it** → slow down, underline keywords
- **C – Wild guess** → stop guessing when you can't eliminate 2 options
- **D – Eliminated wrongly** → study the elimination logic

**Target scores across the mocks:** 70+ by mock #5, 90+ by mock #12, 100+ by mock #20.

## 12. Exam-Day Strategy (GS Paper 1)

1. **Round 1 (60 min):** attempt only questions you're sure of (target 45–55).
2. **Round 2 (40 min):** questions where you can eliminate 2 options (target 25–35 more).
3. **Round 3 (15 min):** look at the rest again. Attempt only if you can eliminate 1 option and have a strong hunch.
4. **Fill the OMR** after each round, not all at the end.
5. **Ideal attempts:** 85–95. Negative marking is ⅓ of the question's marks (−0.66 per wrong answer).
6. **"How many statements are correct" questions:** you need to be sure of every statement, so attempt only if you're confident about each one.

## 14. Golden Rules
1. Finishing the plan matters more than perfection, so don't get stuck on one topic for more than its allotted day.
2. Make one revision source per subject (your short notes).
3. Treat PYQs as the syllabus: if UPSC asked it before, it can ask the next level of it.
4. Mocks are for learning, not for judging yourself. A low score in February is fine.
5. Look after your health. A burnout week costs more than a rest day.
6. Stay away from too many Telegram groups and YouTube toppers' strategies. Follow one plan.
